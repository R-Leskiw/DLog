# Responsive UX Strategy: Field vs. Office

## 1. Field Worker (Mobile-First)
- **Log Entry:** Large input fields. Use "Step-through" forms (one question at a time) to avoid overwhelming the user on a small screen.
- **Camera Access:** Primary action button should be "Add Photo" with direct access to the mobile camera.
- **Messaging:** Sticky bottom input bar (like iMessage/WhatsApp) for quick updates.

## 2. Project Manager (Desktop-Optimized)
- **Log Review:** A "Split-pane" view. List of logs on the left, full log details with high-res photos on the right.
- **Dashboard:** High-level cards showing "Logs submitted today" vs "Missing logs."
- **Messaging:** Wide-screen chat interface with a searchable message history.

## 3. The "Yellow" Brand Implementation
- Use **Yellow (#FACC15)** for "Action" items only (Buttons, active states, alerts). 
- Use **Young Serif** for page titles (e.g., "Daily Report - May 11") to give it a premium, designed feel.
